***[[Sistemas Inteligentes]]***


**DEFINICIÓN DE INTELIGENCIA**
****
Un ser es inteligente si cumple los siguientes aspectos:
- Comunicación.
- Autoconocimiento.
- Memoria y capacidad de procesar nuevas experiencias.
- Intencionalidad.
- Creatividad.
- Capacidad de inferencia y razonamiento.

**INTELIGENCIA ARTIFICIAL**
****
Disciplina científica que se ocupa de crear programas que ejecutan operaciones parecidas al pensamiento humano, tales como el aprendizaje o el razonamiento.
Para resolver una ecuación de segundo grado por ejemplo, no es necesaria una IA.

| Programa convencional | Programa de IA |  |
| ---- | ---- | ---- |
| Procesos algorítmicos | Procesos heurísticos |  |
| Pasos explícitos | Pasos implícitos |  |
| Info. y control integrados | Info y control separados |  |

**PLANTEAMIENTOS**
****
- **Científico**: trata de desarrollar vocabulario, conceptos y métodos que ayuden a comprender y a reproducir comportamiento inteligente.
- **Ingenieril**: utiliza conjunto de métodos que nos permiten adquirir conocimiento de alto nivel y utilizarlo para resolver problemas en dominios de aplicación concretos.

**TIPOS DE PROBLEMAS**
****
- **Según el determinismo**:
	- Deterministas: cada acción de un agente lleva a un estado predecible.
	- Estocásticos: el estado al que se llega depende de un elemento aleatorio además de la acción tomada.
- **Según la observabilidad**:
	- Completa: los sensores del agente le permiten conocer el estado completo del entorno.
	- Parcial: el agente solo puede obtener una noción parcial del estado actual.

| Problema | Determinismo | Observabilidad | N.º agentes |
| ---- | ---- | ---- | ---- |
| Crucigrama | Determinista | Completa | Único |
| Ajedrez | Determinista | Completa | Multiagente |
| Solitario | Determinista | Parcial | Único |
| Conducción autónoma | Estocástico | Parcial | Multiagente |
| Clasificación de imágenes | Determinista | Completa | Único |
