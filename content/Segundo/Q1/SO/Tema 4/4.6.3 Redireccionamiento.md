Los descriptores de archivo 0, 1 y 2 (STDIN_FILENO, STDOUT_FILENO, STDERR_FILENO) corresponden respectivamente a la entrada estándar, salida estándar y el error estándar para un proceso dado.
La entrada estándar y la salida/error estándar pueden redirigirse a un archivo específico.

Las llamadas al sistema **dup**, **dup2**, y **fcntl** con el comando **F_DUPFD** nos permiten realizar la redirección: **dup** duplica el fd y utiliza el n.º más pequeño disponible.

El siguiente código muestra cómo redireccionar la salida estándar del fichero abierto para que sea el fichero "out.txt".
```
int fd = open("out.txt", O_WRONLY); //(1)
close(STDOUT_FILENO);              //(2)
dup(fd);                          //(3)
```
1) El proceso abre el fichero "out.txt" con open(), la cual devuelve el descriptor del fichero abierto, que en este caso es la entrada de menor valor (3).
2) Se cierra el fichero asignado al descriptor de fichero STDOUT_FILENO, que como vimos, se corresponde al descriptor 2. Ahora el archivo no tiene ninguna salida estándar asignada.
3) Duplica el descriptor del fichero "out.txt" con valor 3 en la menor entrada posible (2). Como la entrada 2 almacena el descriptor de fichero del archivo de salida estándar y ahora almacena el mismo valor que el fd de "out.txt", la salida estándar del proceso para a ser el fichero "out.txt".

**ANULAR REDIRECCIONAMIENTO**
Si queremos deshacer la redirección, de modo que cada fichero vuelva a recuperar su E/S original, debemos mantener un **duplicado** del fd de los archivos antes de las modificaciones y redirigir los ficheros a dichos duplicados.
```
int backup, fd;
backup = dup(STDOUT_FILENO);         //(1)
fd = open("out.txt", O_WRONLY);     //(1)
close(STDOUT_FILENO);              //(2)
dup(fd);                          //(3)


close(STDOUT_FILENO);           //(4)
dup(backup);                   //(5)
close(fd);                    //(6)
close(backup);               //(7)
```
