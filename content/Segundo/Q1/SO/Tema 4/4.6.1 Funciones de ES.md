UNIX usa **E/S sin formato**, no importa si leemos o escribimos bytes en los dispositivos. Las funciones para llamar al sistema reciben un **fd** en dirección de memoria y el n.º de bytes transferidos, tanto para leer como para escribir.
- **`int open(const char* path, int flags, mode_t mode);`**
	 Permite abrir un fichero. Es la primera llamada en ejecutarse ya que permite obtener el fd de los ficheros que se modificarán. Sus argumentos son:<font color="#8A5CF5"> path</font>, ruta para llegar al fichero; <font color="#8A5CF5">flags</font>, modos de apertura del fichero; <font color="#8A5CF5">mode</font>, permite asignarle permisos en caso de que fuese necesario crear el fichero. Su **valor de retorno** es un entero que indica el <font color="#8A5CF5">fd</font> para referirse al fichero abierto/creado. En **caso de error** devuelve <font color="#8A5CF5">-1</font>.
- **`int close(int fd);`**
	Permite crear un fichero para evitar modificaciones en él. Su único argumento es el <font color="#8A5CF5">fd</font> que se solicita cerrar. Su **valor de retorno** es 0. En **caso de error** devuelve <font color="#8A5CF5">-1</font>.
- **`ssize_t read (int fd, void *buf, size_t count)`**
- **`ssize_t write (int fd, const void *buf, size_t count`**
	Reciben un <font color="#8A5CF5">fd</font>, una dirección de memoria de origen/destino <font color="#8A5CF5">buf</font> y la cantidad de bytes que deben transferirse <font color="#8A5CF5">count</font>. Su **valor de retorno** es la cantidad de bytes realmente transferidos. La lectura/escritura se realiza en la posición actual dentro del propio archivo.
- **`off_t lseek (int fd, off_t offset, int whence);`**	
	Recibe un <font color="#8A5CF5">fd</font>, la cantidad de bytes a mover <font color="#8A5CF5">offset</font> con respecto al tercer parámetro <font color="#8A5CF5">whence</font>. Este tercer parámetro puede tomar valores:
	- **SEEK_SET**: offset está relacionado con el inicio (pos = 0) del archivo -> establece cur_pos = offset.
	- **SEEK_CUR**: offset está relacionado con la posición actual del archivo -> establece cur_pos = cur_pos + offset.
	- **SEEK_END**: offset está relacionado con el final del archivo (tamaño = N) -> establece cur_pos = N - offset.
- **`ssize_t read (int fd, void *buf, size_t count, off_t offset);`**
- **`ssize_t write (int fd, const void *buf, size_t count, off_t offset);`**
	Similares a read y write, pero también reciben el desplazamiento (bytes desde el inicio del archivo) donde se realiza la lectura o escritura. Estas llamadas no actualizan cur_pos en el archivo.
- **`ssize_t readv (int fd, const struct iovec *io, int iovcnt);`**
- **`ssize_t writedv (int fd, const struct iovec *io, int iovcnt);`**
- **`ssize_t preadv (int fd, const struct iovec *io, int iovcnt);`**
- **`ssize_t pwritev (int fd, const struct iovec *io, int iovcnt);`**
	 Similares a read, write, pread y pwrite. Sin embargo, en lugar de realizar una operación de E/S, es un búfer de memoria único, realizan una operación de E/S en varios búferes iovcnt diferentes que se describen a través del array iov.
	 Cada struct iovec describe un búfer de E/S: su dirección de memoria (iov_base) y la cantidad de bytes a transferir (iov_len).
