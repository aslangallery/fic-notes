Dependiendo del método empleado para comunicar información entre la CPU y los dispositivos, podemos distinguir dos **tipos de transmisión**:
- **E/S con mapeado de memoria**: los dispositivos aparecen en el sistema con sus regiones de memoria visibles, compartiendo espacio de direcciones entre la memoria y los dispositivos. No suelen plantear mucho problema ya que el espacio de E/S es mucho menor que el espacio de direcciones. Para acceder a los registros de controlador, se hace con instrucciones de tipo **MOVE**.
- **E/S con separación de puertos**: se conoce también como **E/S explícita**. Se dispone de un rango de direcciones explícito para los periféricos. A veces hay instrucciones especiales para acceder a este espacio E/S (**IN y OUT de intel**) o un registro de control que activa este espacio (**powerpc**). En estos sistemas también se pueden utilizar los dispositivos mapeados en memoria.

Dependiendo de cómo o **cuándo transmitir** la información entre los dispositivos se distinguen:
- **E/S síncrona**: el proceso tiene que esperar a que la operación E/S se haya completado. Las operaciones están programadas para que se ejecuten coincidiendo con el flanco de activación del reloj de la CPU.
- **E/S asíncrona**: el proceso no tiene que esperar a que se complete la operación E/S. Cuando se haya completado, recibirá una notificación avisando de ello. Dicho aviso trata de la interrupción que genera el controlador del dispositivo al indicarle al CPU que se ha completado la operación.
Dado que la CPU es mucho más rápida que los dispositivos de E/S, una vez iniciada la E/S, el SO asigna la CPU a otra tarea dejando el proceso que inicia la tarea en espera. El proceso percibe la E/S como síncrona aunque es asíncrona.
Muchos SO permiten la E/S asíncrona: el proceso inicia la era y continúa su ejecución. El proceso es avisado por el SO cuando la operación de E/S se ha completado.
